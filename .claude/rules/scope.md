# 범위(비목표)

- PRD.md 비목표에 적힌 기능(예: 카카오톡 자동 연결, 실제 파일 업로드와 보관, AI 자동분석 기능 등)은 만들지 않는다.
- 1인 사용자용 개인 도구입니다 — 회원가입 없음, 다중 사용자 없음, 고객사 직접 접속 없음, 파일 업로드/보관 없음, 외부 연동 없음(카카오톡/이메일/문자), 문서 자동 생성 없음, 분석/AI 기능 없음(모두 범위 밖으로 명시됨 — PRD.md의 비목표와 idea/scope.md의 뺄 기능 참고).
- 예외(미카엘 결정, 2026-10-16): 화면 오른쪽 아래 안내 챗봇은 범위 안이다. 이 챗봇은 PRD.md만 읽고 서비스 사용법을 안내하며, 업무 기록(data/records.csv, 메모 등)을 읽거나 분석하지 않는다. 이 범위를 넘는 AI 기능은 여전히 만들지 않는다.
- 예외(미카엘 결정, 2026-11-03): 구글 계정 로그인(Streamlit st.login)은 범위 안이다. 구글 계정으로 들어와야 화면이 보이고, 들어온 사람의 이름을 화면 위에 보여 준다. 따로 회원가입을 받거나 여러 사용자를 관리하는 기능은 여전히 만들지 않는다.
- 예외(미카엘 결정, 2026-11-04): 로그인 화면의 「👀 둘러보기 (보기만)」는 범위 안이다. 로그인 없이 첫 화면·화면 1·2·3을 볼 수만 있고, 저장·수정·삭제·고객사 추가·메모 남기기·인증 입력·연습용 기록장은 숨기거나 막는다. 오른쪽 위에는 「👀 둘러보는 중 · 나가기」를 보여 준다. 챗봇은 쓸 수 있지만 둘러보기 질문은 저장하지 않고, 지난 질문 목록은 숨기며, 한 번 들어와 5번까지만 묻는다. 둘러보는 사람마다 계정을 만들거나 따로 관리하는 기능은 여전히 만들지 않는다.
- 예외(미카엘 결정, 2026-11-05): 관리자 구분은 범위 안이다. 구글 계정 메일이 .streamlit/secrets.toml의 ADMIN_EMAILS 목록에 있으면 관리자로 보고, 관리자에게만 왼쪽 사이드바 「관리」 버튼과 「관리자만 보는 화면입니다」 한 줄이 있는 관리 화면을 보여 준다. 관리자가 아니면 관리 화면 코드도 돌지 않는다. 둘러보기 손님은 관리자가 아니고, ADMIN_EMAILS를 찾지 못하면 관리자가 없는 것으로 본다. 관리 화면에서 사용자를 추가하거나 관리하는 기능은 여전히 만들지 않는다.
- 예외(미카엘 결정, 2026-11-05): 연습용 기록장은 로그인한 메일로 글을 저장한다. 일반 사용자는 자기 줄만 구글 계정 이름으로 보고, 관리자는 전체를 본다. 이 밖에 사용자별로 자료를 나누는 기능은 여전히 만들지 않는다.
