# 📋 개인용 관리판

- 써 보기 : [https://consulting-dashboard.streamlit.app](https://consulting-dashboard.streamlit.app)
- 한 줄 소개 : 여러 고객사를 혼자 관리하는 컨설턴트가 고객사를 고르면 최근 작업·진행상태·다음 할 일·마감일을 한 화면에서 확인하고, 업체별 폴더를 일일이 뒤지지 않고 업무를 바로 이어갈 수 있는 개인용 관리판입니다.

## 무엇을 하는 서비스인가

여러 고객사 업무를 한 화면에 모아 보는 개인용 관리판입니다.
고객사를 고르면 진행상태·마감일 요약과 최근 작업·다음 할 일을 한 화면에서 확인할 수 있어, 업체별 폴더를 일일이 뒤지지 않고 업무를 바로 이어갈 수 있습니다.
여러 회사의 일을 동시에 챙기다 보니 일정과 결정한 내용을 놓칠 때가 있어서, 회사별로 한눈에 보려고 직접 만들었습니다.

- 화면 1에서 「마감 챙길 업무」와 「중요 표시한 업무」를 먼저 보여 줍니다. 「마감 챙길 업무」는 지금은 샘플 자료만 보여 주고, 「중요 표시한 업무」는 화면 3에서 중요 표시해 저장한 기록도 보여 줍니다.
- 업무 기록을 적고 고쳐 저장하면, 관리판을 다시 열어도 남아 있습니다.
- 고객사별로 한 줄 메모를 남기면 날짜와 함께 쌓입니다.

## 누구를 위한 것인가

여러 고객사를 혼자 관리하는 중소기업 컨설턴트를 위한 1인용 도구입니다.
정책자금·기업인증·특허·연구소·ESG(환경·사회·지배구조)·수출·인사노무처럼 고객사마다 다른 업무를 동시에 진행하다 보니, 최근 작업과 다음 할 일을 기억하기 어렵고 파일 위치와 수정 기록이 흩어지는 문제를 줄이려고 만들었습니다.
아침 업무 확인, 고객사 통화·미팅 전, 서류 작성·수정 후 기록, 며칠 뒤 업무를 다시 이어갈 때 씁니다.

## 어떻게 쓰나

**첫 화면**

1. 「시작하기」를 누르면 화면 1로 갑니다.

**화면 1 · 오늘의 업무**

2. 「마감 챙길 업무」(마감 지남 / 다가오는 마감)와 「중요 표시한 업무」 목록을 확인합니다. 「마감 챙길 업무」는 지금은 샘플 자료만 보여 주고, 「중요 표시한 업무」는 화면 3에서 중요 표시해 저장한 기록도 보여 줍니다. 각 줄의 「>」를 누르면 그 고객사의 화면 2로 갑니다.
3. 새 고객사는 「새 고객사 이름」 칸에 이름을 적고 「고객사 추가」를 누릅니다. 추가한 고객사는 선택 칸에 바로 골라집니다.
4. 「확인할 고객사 선택」에서 고객사를 고르고 「확인」을 누르면 화면 2로 갑니다. 고르지 않고 누르면 "확인할 고객사를 먼저 선택해 주세요" 안내가 나옵니다.

**화면 2 · 고객사 현황**

5. 맨 위에서 고객사명·진행상태·마감일 요약을 봅니다.
6. 「지금 현황」 탭에서 ① 최근 작업, ② 다음 할 일을 봅니다.
7. 「파일·수정 이력」 탭에서 ③ 파일 위치(오른쪽 위 복사 아이콘으로 경로 복사)와 ④ 수정내용을 봅니다. 지금은 샘플 자료만 보여 주고, 화면 3에서 저장한 기록은 이 탭에 나오지 않습니다.
8. 오른쪽 「⑤ 한 줄 메모」 칸에 메모를 적고 「남기기」를 누르면 날짜·시각과 함께 아래 목록에 쌓입니다.
9. 「업무 기록 작성·수정」을 누르면 화면 3으로, 「목록으로」를 누르면 화면 1로 갑니다.

**화면 3 · 업무 기록 작성·수정**

10. 왼쪽 「업무 기록 입력」에 작업내용·진행상태·다음 할 일·마감일·파일 위치·수정내용을 적고, 필요하면 「⭐ 중요 표시」를 체크한 뒤 「저장」을 누릅니다. 저장한 기록은 오른쪽 「기존 기록 목록」에 바로 나타납니다.
11. 이미 남긴 기록을 고치려면 「기존 기록 목록」에서 「고르기」를 누릅니다. 입력 칸에 그 값이 채워지면 고친 뒤 「저장」을 누릅니다.
12. 고른 기록을 비우고 새 기록을 쓰려면 「새로 쓰기」를 누릅니다.
13. 기록을 지우려면 「삭제」를 누른 뒤, 한 번 더 묻는 자리에서 「지우기」(또는 「취소」)를 누릅니다. 지운 기록은 되돌릴 수 없습니다.
14. 「고객사 현황으로」를 누르면 화면 2로 돌아갑니다.

**어느 화면에서나**

15. 화면 1·2·3의 왼쪽 사이드바(옆 메뉴)에서 「← 첫 화면으로」를 누르면 첫 화면으로 돌아갑니다.
16. 오른쪽 아래 「✨」 아이콘을 누르면 관리판 안내 챗봇이 열립니다. 질문을 적고 「보내기」를 누르면 서비스 사용법을 세 줄로 답해 줍니다. 챗봇은 PRD.md(제품 요구사항 문서)만 읽고 답하며, 업무 기록은 읽지 않습니다. 아래 「지난 대화」에서 이전 질문과 답을 다시 볼 수 있습니다.
