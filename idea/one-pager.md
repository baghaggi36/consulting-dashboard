# 고객사 업무 이어가기 관리판

## 1. 서비스 한 줄 소개

여러 고객사를 혼자 관리하는 중소기업 컨설턴트가 고객사별 최근 작업과 다음 할 일을 확인하고, 작업내용·파일 위치·수정내용을 기록하여 중단된 업무를 바로 이어가는 개인용 관리판이다.

## 2. 핵심 사용자

10년 이상 경력의 중소기업 컨설턴트 미카엘이 사용한다.

미카엘은 여러 고객사를 혼자 관리하며 정책자금, 기업인증, 특허, 연구소, ESG, 수출, 인사·노무 등 서로 다른 업무를 동시에 진행한다.

## 3. 해결하려는 문제

- 고객사별 최근 작업을 기억하기 어렵다.
- 다음에 무엇을 해야 하는지 확인하려면 카카오톡이나 메모를 다시 찾아봐야 한다.
- 작성하거나 수정한 파일의 위치를 바로 찾기 어렵다.
- 파일에서 무엇을 수정했는지에 관한 기록이 흩어져 있다.
- 중단된 업무를 다시 시작할 때 이전 내용을 파악하는 데 시간이 걸린다.

## 4. 제공하려는 가치

관리판을 열면 고객사별 최근 작업, 다음 할 일, 마감일과 파일 위치가 먼저 보인다.

업무를 마친 뒤 작업내용과 수정내용을 기록해 두면 다음 업무를 빠르게 이어갈 수 있다.

## 5. 핵심 기능

### 고객사 관리

- 고객사 목록 확인
- 고객사별 진행상황 확인
- 주요 컨설팅 분야 확인

### 업무 확인

- 마감일과 중요도에 따른 우선 처리 업무 확인
- 최근 작업내용과 작업일자 확인
- 다음 할 일과 마감일 확인
- 중요도와 진행상태 확인
- 관련 파일 위치 확인

### 작업 기록

- 새로운 작업내용 기록
- 다음 할 일과 마감일 기록
- 파일 위치 기록
- 주요 수정내용 기록
- 참고사항 기록
- 이전 작업기록 확인

## 6. 핵심 화면

### 화면 1. 오늘의 업무

- 전체 고객사와 진행 중인 업무 요약
- 마감일이 가까운 업무
- 우선 처리할 업무
- 고객사 목록
- 새 작업 기록 버튼

### 화면 2. 고객사 상세

- 고객사 기본정보
- 현재 진행 중인 업무와 진행상태 확인
- 다음 할 일과 마감일
- 최근 작업내용
- 관련 파일 위치
- 주요 수정내용
- 참고사항
- 이전 작업기록

### 화면 3. 작업기록 입력

- 고객사명
- 작업일자
- 작업내용
- 진행상태
- 다음 할 일
- 마감일
- 중요도
- 파일 위치
- 주요 수정내용
- 참고사항


## 7. 핵심 사용 흐름

1. 관리판을 연다.
2. 우선 처리할 업무를 확인한다.
3. 업무를 진행할 고객사를 선택한다.
4. 고객사의 최근 작업내용을 확인한다.
5. 다음 할 일과 관련 파일 위치를 확인한다.
6. 실제 업무를 진행한다.
7. 새로운 작업내용과 다음 할 일을 기록한다.
8. 저장한 내용을 관리판에 반영한다.

### 한 줄 흐름

관리판 열기 → 우선업무 확인 → 고객사 선택 → 최근 작업 확인 → 업무 진행 → 새로운 작업기록 저장

## 8. 첫 번째 버전의 범위

첫 번째 버전은 미카엘 혼자 사용하는 개인용 관리판으로 만든다.

고객사별 최근 작업, 다음 할 일, 마감일, 파일 위치와 수정내용을 확인하고 새로운 작업기록을 남길 수 있게 한다.

실제 업무에 매일 사용할 수 있는 가장 기본적인 기능을 먼저 완성한다.


## 9. 첫 번째 버전에서 제외할 기능

- 여러 직원이 함께 사용하는 협업 기능
- 사용자별 권한관리
- 고객사가 직접 접속하는 기능
- 회원가입과 로그인
- 카카오톡과 이메일 자동연결
- 문자와 알림 자동발송
- 실제 파일 업로드와 보관
- 회계와 세금계산서 관리
- 계약서와 신청서 자동작성
- 복잡한 통계와 그래프
- 스마트폰 전용 앱
- AI 자동분석

위 기능들은 첫 번째 버전이 완성된 후 필요성과 우선순위를 검토하여 추가한다.

## 10. 완성 기준

미카엘이 관리판을 열고 다음 과정을 자연스럽게 수행할 수 있으면 첫 번째 버전이 완성된 것으로 본다.

1. 우선 처리할 업무를 확인한다.
2. 업무를 진행할 고객사를 선택한다.
3. 최근 작업과 다음 할 일을 확인한다.
4. 관련 파일 위치와 수정내용을 확인한다.
5. 실제 업무를 처리한다.
6. 새로운 작업내용과 다음 할 일을 기록한다.
7. 저장한 내용이 고객사 업무현황에 반영된 것을 확인한다.

## 11. 기대효과

- 고객사 업무 누락 방지
- 마감일 관리 강화
- 파일을 찾는 시간 단축
- 중단된 업무의 빠른 재개
- 고객사별 진행상황의 체계적인 관리
- 여러 고객사를 혼자서도 안정적으로 관리
