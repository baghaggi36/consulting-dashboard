# 관리판 화면 구성

## 화면 1. 오늘의 업무

관리판을 열었을 때 가장 먼저 보이는 화면이다.

### 보여줄 내용

- 오늘 해야 할 일
- 마감일이 가까운 업무
- 중요도가 높은 업무
- 고객사명
- 진행상태
- 전체 고객사 수
- 진행 중인 업무 수

### 이 화면에서 할 수 있는 일

- 우선 처리할 업무 확인
- 고객사 선택
- 고객사 상세화면으로 이동
- 새로운 작업기록 입력화면으로 이동

---

## 화면 2. 고객사 상세

선택한 고객사의 최근 작업과 현재 진행상황을 확인하는 화면이다.

### 보여줄 내용

- 고객사명
- 주요 컨설팅 분야
- 현재 진행 중인 업무
- 최근 작업일자
- 최근 작업내용
- 다음 할 일
- 마감일
- 파일 위치
- 주요 수정내용
- 참고사항
- 이전 작업기록

### 이 화면에서 할 수 있는 일

- 최근 작업 확인
- 다음 할 일 확인
- 관련 파일 위치 확인
- 이전 작업기록 확인
- 새로운 작업기록 입력

---

## 화면 3. 작업기록 입력

업무를 마친 뒤 처리한 내용을 기록하는 화면이다.

### 입력할 내용

- 고객사명
- 작업일자
- 작업내용
- 진행상태
- 다음 할 일
- 마감일
- 중요도
- 파일 위치
- 주요 수정내용
- 참고사항

### 버튼

- 저장
- 취소

---

## 화면 이동 흐름

오늘의 업무 화면
→ 고객사 선택
→ 고객사 상세화면
→ 최근 작업과 다음 할 일 확인
→ 작업 진행
→ 작업기록 입력
→ 저장
→ 고객사 상세화면에 반영

## 첫 번째 버전에 필요한 화면

첫 번째 버전은 다음 세 화면만 만든다.

1. 오늘의 업무
2. 고객사 상세
3. 작업기록 입력
