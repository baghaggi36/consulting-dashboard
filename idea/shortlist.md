# 내 아이디어 후보 3가지

## 후보 1 - 지원사업 상담 화면

- 만들고 싶은 것 : 고객사의 업종·지역·매출을 입력하면, 미리 정리해 둔 자료에서 신청 가능한 정책자금과 지원사업 후보를 보여주는 화면
- 내가 겪는 불편 : 고객사에 맞는 지원사업을 찾기 위해 여러 기관의 공고를 반복해서 확인해야 한다.
- 팀에서 받은 의견 : 수업 때 팀원들과 이야기한 뒤, 아이디어 이름과 내용을 직접 정리했다.
- 만들 수 있는 범위 : 미리 정리한 지원사업 표를 읽어 고객사 조건에 맞는 후보를 보여주는 것까지

## 후보 2 - 청약서 자동입력 양식

- 만들고 싶은 것 : 고객사 이름을 선택하면 저장된 주소와 사업자정보가 청약서의 알맞은 칸에 자동으로 들어가는 양식
- 내가 겪는 불편 : 청약서를 작성할 때마다 기존 서류를 찾아 주소와 기본정보를 반복해서 옮겨 적는다.
- 팀에서 받은 의견 : 수업 때 팀원들과 이야기한 뒤, 아이디어 이름과 내용을 직접 정리했다.
- 만들 수 있는 범위 : 고객정보 표에서 선택한 회사의 정보를 찾아 청약서에 채우고 문서로 저장하는 것까지

## 후보 3 - 고객사 진행관리판

- 만들고 싶은 것 : 고객사 이름을 누르면 최근 작업내용·현재 진행단계·다음 할 일·파일 위치를 한 화면에서 보여주는 관리판
- 내가 겪는 불편 : 여러 고객사의 업무를 동시에 진행하다 보니, 이전 작업과 다음 할 일을 기억이나 카톡에 의존하게 된다.
- 팀에서 받은 의견 : 수업 때 팀원들과 이야기한 뒤, 아이디어 이름과 내용을 직접 정리했다.
- 만들 수 있는 범위 : 직접 정리한 고객정보 표를 읽어 고객사별 진행 상황과 다음 할 일을 보여주는 것까지
## 아직 못 버린 것

- 새로운 지원사업 공고가 올라오면 조건에 맞는 고객사를 알려주는 자동 알림 - 여러 기관의 공고를 실시간으로 가져오는 기능은 지금 과정에서 만들기 커 보이지만 실제 업무에 유용해 미련이 남는다
- 팀이 준 말 : 정양호님 - 나라면 쓰겠다. 중소벤처기업부와 각 시·군·구에 흩어진 지원사업을 한곳에 모아, 조달청 나라장터처럼 검색하고 확인할 수 있으면 유용할 것 같다.
